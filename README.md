# VibeChat 💬

A chill place to hang out and chat in real time.

**Live at: https://venulousthyduckulous.github.io/vibechat/**

## How to use

1. **Sign up** — pick a username and password.
2. **Join a room** — click any public room, or enter the password for a private one.
3. **Or create your own** — name it, choose public or password-only, and share it with friends.
4. **Chat** — messages appear instantly. Links turn clickable automatically.

## Features

- 🌍 Public rooms and 🔒 password-protected rooms
- 💬 Real-time messages with history
- 🟢 See who's online in each room
- ⌨️ Typing indicators
- 🖼️ Profile pictures, username & password changes
- 📣 @mentions with unread badges
- 📌 Announcements tab (owner posts, everyone reads)
- 🎮 Minigames with leaderboards
- 🗑️ Mods can delete messages right from chat
- 🌙 Dark mode built in
- 🎨 Colour themes (including light mode)
- 👑 Room creators can close their own rooms
- 🛡️ Moderation — admins can remove bad rooms and messages, the owner can ban users

## Rules of the vibe

- Be kind. Don't spam.
- Room creators can close rooms that get out of hand.
- Private room passwords stay private — don't share them publicly.
